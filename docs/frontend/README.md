# How to use the Venduzily Dashboard documentation

1. Read `AGENTS.md` and `.github/copilot-instructions.md`.
2. Select **one** item in `implementation-plan.md` (begin with F01).
3. Agent reads `architecture.md`, `design-system.md`, `coding-standards.md`, `api-integration.md`, `authentication.md`, `testing-strategy.md`, the relevant module doc and `open-questions.md`.
4. Compare backend reference files and the **full machine-readable** OpenAPI contract stored at `../contracts/venduzily-openapi.json`.
5. Implement, test, report scope/results, and await the next task.

This is a documentation-only preparation. No frontend UI or API code has been implemented by this package. Existing starter app files remain unchanged.
